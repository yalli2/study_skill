# 🚀 Study Skill Quest · 공부력 레벨업

학생들이 **스스로 공부하는 힘(자기주도학습)**을 기르도록 만든 인터랙티브 공부법 사이트입니다.

👉 사이트: https://yalli2.github.io/study_skill/

## 구성
- **🩺 공부 습관 진단** — 18문항 진단 + 레이더 차트, 약한 영역에 맞는 장·도구 추천 / 12문항 학습 선호 탐색
- **🗺️ 퀘스트 (7개 월드, 49개 레슨)** — 공부의 원리 · 준비와 목표 · 정보 다루기 · 온라인 학습 · 복습 기술 · 시험 기술 · 마음 다루기
  - 레슨마다 핵심 정리, 과학 팩트체크, 미니게임, 확신도(메타인지) 퀴즈, 장별 보스 퀴즈
- **🔬 과학 공부법 랩** — 인출 연습, 간격 반복(망각 곡선 실험), 교차 학습, 정교화, 구체적 예시, 이중 부호화(그림판), 파인만 기법, 메타인지 보정 점수, WOOP·If-Then, 효과 낮은 습관
- **🛠️ 도구함 (13개)** — 집중 타이머, 라이트너 플래시카드, 시험 D-day 간격 복습 계획, SMART·WOOP 목표, 우선순위 할 일·거꾸로 계획, 주간 시간표, 24시간 파이차트, 코넬 노트, 마인드맵, 암기 문장 메이커, 에세이 질문 분해기, 마음 체크 & 호흡, 학습 일지
- **🏆 게임화** — XP·레벨, 연속 학습일, 오늘의 미션, 배지 20종

기록은 각 기기의 브라우저(localStorage)에 저장되며, 내 기록 페이지에서 백업·불러오기가 가능합니다.

## 참고
DK 「Help Your Kids With Study Skills」(2016)의 7개 장 구성을 바탕으로 내용을 새로 쓰고 재구성했으며, Dunlosky 외(2013), The Learning Scientists, EEF 메타인지 연구, Pashler 외(2008) 등 학습과학 연구를 더했습니다. 전체 목록은 사이트의 「참고 자료」 페이지에 있습니다.
